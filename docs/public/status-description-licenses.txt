HTTP status descriptions: attribution and modifications

The English descriptions were imported from the Description sections of
HTTP Cats (https://http.cat/), excluding See Also. Most originate from MDN
Web Docs and are attributed to Mozilla Contributors under CC BY-SA 2.5:
https://creativecommons.org/licenses/by-sa/2.5/

The original source and intermediary URLs are listed below. Current MDN
reference links displayed by the site may differ following MDN redirects.
Descriptions for 306 and 505 are original project summaries. Entries whose
source is HTTP Cats rather than MDN retain that provenance in this list.
HTTP Cats copyright and MIT permission notice are reproduced below.

Modifications by the 200 OK project:
- Removed See Also sections and presentation-specific markup.
- Added German, Spanish, French, Russian, Simplified Chinese and Korean
  translations, retaining the original paragraph/list structure and code.
- Translation drafts were generated with Google Translate and edited for
  technical terminology. These are project translations, not official MDN
  translations. The localized source links are references to MDN pages.
- Localized MDN links where corresponding pages exist; otherwise kept the
  English MDN reference. The source text itself has not been replaced with
  a newer MDN revision.
- Translations of CC BY-SA descriptions remain under CC BY-SA 2.5.
